# QARAVAN Events — events.qaravan.org

Страница со всеми ближайшими событиями для ссылки в Instagram bio: **https://events.qaravan.org**

Хостинг: GitHub Pages (этот репозиторий, ветка `main`). Домен: CNAME-запись `events → ashtyngon.github.io` в DNS-настройках qaravan.org (Wix).

## Как обновить события

1. Откройте [`index.html`](index.html) и нажмите карандаш («Edit this file»).
2. Меняйте только текст в кавычках в списке `EVENTS`. Одно событие — один блок `{ ... }`: добавить — скопируйте соседний и поправьте, отменили — сотрите блок. Страница двуязычная (переключатель RU / EN в шапке), поэтому у каждого события две полные половины: `en` и `ru`, в каждой `title` (название), `about` (одна короткая строка о событии) и `place` (где). Ещё поля: `dates` — дата `"ГГГГ-ММ-ДД"` (если дат несколько, как у группы поддержки, — через запятую), `time` — время начала по 24 часа (`"19:30"`, у поездок — время сбора), `type` — тип события, как в колонке Category на доске monday (`support`, `community`, `resources`, `culture`, `action`; от него цвет флажка), `link` — ссылка. Число, день недели, месяц, время в формате каждого языка и порядок карточек страница считает сама.
3. Нажмите «Commit changes». Сайт обновится сам через 1–2 минуты.

Прошедшие события переносить никуда не нужно — это делает робот (ниже). Список `ARCHIVE` руками не трогайте.

Подробная инструкция продублирована комментарием прямо в `index.html`, перед списком событий.

## Робот: прошедшие события уходят в архив сами

Каждую ночь (4:30 по Нью-Йорку) workflow [«archive past events»](.github/workflows/archive-past.yml) запускает `robot/archive-past.mjs`: он убирает из `EVENTS` всё, что уже прошло, и складывает в `ARCHIVE` по месяцам — прошлые месяцы показываются под текущим списком свёрнутым блоком «Показать». У события с несколькими датами прошедшие даты уезжают в архив, будущие остаются в карточке. Если что-то переехало, робот коммитит `index.html` в `main`, и сайт пересобирается сам. Красный прогон — значит, робот не смог прочитать список (обычно лишняя запятая или кавычка в `EVENTS`) или у какого-то события не заполнена одна из половин, `en` или `ru` (в логе написано, у какого и чего не хватает); сайт при этом не ломается, просто прошедшее остаётся наверху до починки.

Запустить сейчас: Actions → «archive past events» → Run workflow (галочка «Dry run» — только показать, что переедет). Локально: `node robot/archive-past.mjs` (`TODAY=2026-10-01` — притвориться, что сегодня другой день; `DRY_RUN=1` — не записывать файл).

## Дизайн

Страница собрана по дизайн-системе QARAVAN (ревизия 2026-09): шрифты Fira Sans и Fira Sans Condensed (файлы в `assets/fonts/`, лицензия OFL), официальный логотип (`assets/logo-wordmark.svg`, для тёмного подвала — `logo-wordmark-dark.svg`; не перерисовывать), белая страница, квадратные карточки с тонкой линией, цвета бренда — только флажками типов событий. Язык: `?lang=en` / `?lang=ru` в ссылке, иначе последний выбор человека, иначе язык браузера.

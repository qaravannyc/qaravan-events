# QARAVAN Events: бывший events.qaravan.org

events.qaravan.org закрыт (владелец, 2026-11-07). Этот адрес теперь обслуживает сайт qaravan.org (репозиторий qaravan-site): оба календаря `.ics` отвечают там же, где были, с теми же событиями, а все остальные адреса переводят на qaravan.org:

- `/` → https://www.qaravan.org/events/ (по-русски /ru/events/);
- `/bio/` → https://www.qaravan.org/bio/;
- `/newsletter/oct13/`, `/oct27/`, `/quiz/` → те же страницы на www.qaravan.org;
- `/oct19/` → https://www.qaravan.org/files/ucheba-v-ssha.pdf.

События ведут только на qaravan.org (Site management → Events). Telegram-бот и календари берут их оттуда. Списки `EVENTS` и `ARCHIVE` в `index.html` и роботы в `robot/` остались здесь как архив: их больше никто не читает и не запускает. Страницы в этом репозитории (`bio/`, `newsletter/`, `oct19/`, `oct27/`, `quiz/`) тоже старые копии: живые лежат в qaravan-site, править нужно там.

Здесь по-прежнему нужен только код сервера страницы bio: [`bio-worker/worker.mjs`](bio-worker/worker.mjs).

## Ссылки для Instagram bio

Страница со всеми ссылками для bio: **https://www.qaravan.org/bio/** (старый адрес events.qaravan.org/bio/ переводит туда). Два языка, RU / EN.

**Как править.** Внизу страницы нажмите «Редактировать ссылки» (или откройте `/bio/#edit`), введите пароль команды и своё имя (имя нужно только для истории). Дальше:

- ссылку можно перетащить за ручку слева (на телефоне тоже) или двигать стрелками; на клавиатуре — стрелки вверх и вниз на ручке;
- **важность** задаёт, как ссылка выглядит: «Главная» — тёмная кнопка, «Обычная» — карточка с рамкой, «Тихая» — строка текста. Главных держите две-три, иначе выделять нечего;
- «Метка» — жёлтая надпись над названием («New» / «Новое», «В прессе»); «Цвет флажка» — квадрат цвета бренда у названия;
- «Показывать с» и «Показывать до» — даты по нью-йоркскому времени: сбор или анонс сам появится и сам исчезнет;
- «Скрыть со страницы» прячет ссылку, не удаляя её; «Дублировать» и «Удалить» (удаление можно вернуть сразу кнопкой «Вернуть»);
- «Добавить заголовок» делает подпись раздела («Поддержать нас», «Для новичков»), чтобы длинный список не слипался;
- справа (на телефоне — кнопка «Предпросмотр») видно страницу такой, какой её увидят гости. Правки попадают на страницу только после «Опубликовать»;
- «Версии» хранит последние 40 публикаций: кто, когда, сколько ссылок. Любую можно вернуть. Если двое публикуют одновременно, второго предупредят, а не сотрут правки первого;
- «Скачать копию» сохраняет список файлом.

Названия и подписи у каждой ссылки двуязычные; если заполнен один язык, на другом покажется он.

**Пароль.** Один общий пароль команды. Сменить его может любой, кто его знает: в редакторе кнопка «Сменить пароль» (нужен нынешний пароль). После смены все остальные выходят из редактора и входят уже с новым.

**Как устроено.** Страница статическая (qaravan-site, `site/bio/`), а список ссылок и пароль хранит маленький сервер `qaravan-bio` на Cloudflare (тот же аккаунт QARAVAN, что у телеграм-бота). Пароля нет ни в репозитории, ни на странице: сервер хранит только его отпечаток (хеш). Код сервера — [`bio-worker/worker.mjs`](bio-worker/worker.mjs), выкладывает его workflow «bio worker» в репозитории events-robot: после правки кода запустите его там (Actions → bio worker → Run workflow). Если сервер недоступен, страница показывает последний список, который видел этот браузер, или `site/bio/links.json` в qaravan-site.

**Проверить у себя без Cloudflare:** `EDIT_PASSWORD=test-password node bio-worker/dev-server.mjs`, затем http://localhost:8787/bio/ (данные в памяти, после остановки пропадают; страница там — старая копия из `bio/`). Тесты сервера: `node --test bio-worker/worker.test.mjs`.

**Сколько людей нажимает.** Когда в `COUNTER` в `site/bio/index.html` (qaravan-site) стоит адрес GoatCounter, нажатия считаются по ссылкам: `bio-link-<название>`, а `bio-unique-people` — сколько разных людей нажали хоть на одну. Без cookie и личных данных, при «Do Not Track» не считается, пока человек редактирует — тоже.
